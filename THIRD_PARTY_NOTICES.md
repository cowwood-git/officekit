# 오픈소스 고지

이 사이트는 아래 오픈소스를 사용합니다. 각 라이선스 전문은 패키지 저장소를 참고하세요.

| 패키지                 | 용도                     | 라이선스                                     |
| ---------------------- | ------------------------ | -------------------------------------------- |
| Astro                  | 정적 사이트 생성         | MIT                                          |
| pdf-lib                | PDF 생성·병합·분할       | MIT                                          |
| pdf.js (pdfjs-dist)    | PDF 렌더링               | Apache-2.0                                   |
| JSZip                  | ZIP 생성                 | MIT 또는 GPLv3 (이 프로젝트는 MIT 조건 사용) |
| qrcode                 | QR 코드 생성             | MIT                                          |
| jsQR                   | QR 코드 디코딩           | Apache-2.0                                   |
| tesseract.js           | 이미지·PDF OCR           | Apache-2.0                                   |
| mammoth                | DOCX 본문 변환           | BSD-2-Clause                                 |
| DOMPurify              | 변환된 HTML 정화         | MPL-2.0 또는 Apache-2.0                      |
| SheetJS (xlsx)         | CSV·XLSX 파싱            | Apache-2.0                                   |
| @aiden0z/pptx-renderer | PPTX 슬라이드 렌더링     | Apache-2.0                                   |
| ECharts                | PPTX 차트 렌더링         | Apache-2.0                                   |
| mtx-decompressor       | PPTX EMF 압축 해제       | MPL-2.0                                      |
| @rhwp/core             | HWP→HWPX 변환·파싱       | MIT                                          |
| @mdgate/doc            | 구형 DOC → Markdown      | MIT                                          |
| marked                 | Markdown → HTML          | MIT                                          |
| @web-ppt/core          | PPT 97-2003 → SVG        | MIT                                          |
| @mdgate/*              | DOC 파싱 보조            | MIT                                          |
| heic2any               | HEIC 디코딩              | MIT                                          |
| korean-holidays        | 한국 공휴일 계산         | MIT                                          |
| korean-lunar-calendar  | 음력 변환                | MIT                                          |
| exifr                  | 이미지 EXIF 파싱         | MIT                                          |
| Phosphor Icons         | 도구 아이콘(duotone)     | MIT                                          |
| @pdf-lib/fontkit       | 폰트 임베드              | MIT                                          |
| NanumGothic            | PDF 양식 한글 폰트       | SIL Open Font License 1.1                    |
| html-to-image          | DOM 페이지 캡처          | MIT                                          |
| Sharp                  | OG 이미지 생성 (빌드 시) | Apache-2.0                                   |
| Biome                  | 린트·포맷                | MIT                                          |
| Vitest                 | 테스트                   | MIT                                          |

PDF.js의 폰트 매핑(cmapps)과 표준 폰트는 Apache-2.0 라이선스로 배포됩니다.
NanumGothic 라이선스 전문은 [`public/fonts/NanumGothic-OFL.txt`](public/fonts/NanumGothic-OFL.txt)에 있습니다.
